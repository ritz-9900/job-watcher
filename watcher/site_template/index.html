Set up Sync (one time)

Sync starts a scan on GitHub, so this browser needs a GitHub token that can only run this repository's workflows. The token is saved in this browser only, never in the repository.

  1. Create a fine-grained token while signed in as the repository owner.
  2. Repository access: Only select repositories → this repository.
  3. Repository permissions: Actions → Read and write. Nothing else.
  4. Set an expiry date, generate it, and paste it below.

Sync is set up in this browser.
