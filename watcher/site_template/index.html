Sync applied marks across devices

Your marks and a GitHub token are saved, encrypted with your passphrase, in a Gist on your GitHub account. On other devices you only type the passphrase.

  1. Create a fine-grained token (signed in as the owner of this dashboard).
  2. Repository access: Public repositories. Account permissions: Gists → Read and write. Nothing else.
  3. Choose an expiry (e.g. 1 year), generate it, and paste it below.

Use four or more random words, e.g. maple orbit candle tuesday. The encrypted data is publicly downloadable, so a short passphrase could be guessed. It cannot be recovered if forgotten.
